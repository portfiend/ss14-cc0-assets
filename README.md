# Portfiend's Public Domain SS14 Resource Dump

This is a repository containing all of my CC0-1.0 licensed sprites and assets for the game Space Station 14. Anything I make that isn't an edit of another sprite goes here.

## Why?

I don't care about things like "intellectual ownership" or "copyright" and believe everything I make should be as shareable as possible. I'm already making $0 off of these things.

## License Adjustments

Some of these sprites had different copyright fields when they were initially merged to their respective repositories. In this repository, I claim them as my own wholly original work and re-license them to CC0-1.0.

In all of these cases, I went and looked at the .png files and realized that they aren't actually "derivative" - at best they might reuse color palettes (and palettes aren't copyrightable). This sometimes happens when I take an RSI folder and split it into multiple folders as I work.

Some of the textures in these folders may be recognizable as originally from SS13 furry servers. That's because I used to be a developer for SS13 furry servers. I used a different name.

## What about [X]?

It's possible I missed something! I don't keep a comprehensive collection of all my work, so I had to pick all of these sprites out by searching my own name on repositories I've worked on. Feel free to show me a sprite I've made and ask me if it's CC0-1.0 or not. At worst, it might be CC-BY-SA-3.0 or something instead.
